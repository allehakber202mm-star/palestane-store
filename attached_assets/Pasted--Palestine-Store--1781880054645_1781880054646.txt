أنشئ لوحة تحكم حقيقية ومتكاملة بالكامل لموقع "متجر فلسطين - Palestine Store"، وليست مجرد واجهة تصميم أو بيانات وهمية.

جميع البيانات يجب أن تحفظ فعلياً داخل قاعدة بيانات MongoDB وتظهر مباشرة داخل الموقع.

المطلوب:

* أي حساب يتم إضافته من لوحة التحكم يظهر مباشرة داخل الموقع.
* أي تعديل على السعر أو عدد المتابعين أو الصورة أو الوصف ينعكس فوراً داخل الموقع.
* عند حذف الحساب يتم حذفه نهائياً من قاعدة البيانات.
* عند تحديد "تم البيع" يتم تحديث الحالة داخل الموقع مباشرة.
* جميع العمليات CRUD يجب أن تعمل بشكل فعلي:

Create
Read
Update
Delete

بدون أي بيانات Mock أو Fake أو Static JSON.

استخدم:

Frontend:
React + TypeScript + TailwindCSS

Backend:
Node.js + Express

Database:
MongoDB Atlas

Storage:
Cloudinary

Authentication:
JWT + bcrypt

State Management:
Zustand

أنشئ REST API حقيقية تشمل:

POST /api/auth/login

GET /api/accounts

POST /api/accounts

PUT /api/accounts/:id

DELETE /api/accounts/:id

GET /api/settings

PUT /api/settings

GET /api/stats

POST /api/upload

يجب حماية جميع API الخاصة بالإدارة باستخدام JWT Middleware.

لوحة الإدارة تكون على:

/admin

ولا يظهر رابطها للزوار.

جميع عمليات إضافة أو تعديل الحسابات تتم داخل Modal أو Drawer داخل نفس الصفحة:

/admin/accounts

دون الانتقال إلى صفحات جديدة.

الموقع يجب أن يحتوي على:

* MongoDB متصلة فعلياً.

* تسجيل زيارات حقيقي.

* إحصائيات حقيقية.
* SEO حقيقي.
