المطلوب تنفيذ التعديلات التالية بالكامل:

========================================
أولاً: إضافة قسم تيك توك أرباح داخل المتجر ولوحة التحكم
========================================

إضافة قسم جديد باسم:

💰 تيك توك أرباح

ويظهر مع الأقسام:

- تيك توك
- تيك توك أرباح
- إنستغرام
- فيسبوك

داخل لوحة التحكم:

1- إضافة خيار "تيك توك أرباح" ضمن تصنيف الحسابات.
2- إمكانية إضافة الحسابات إليه مباشرة.
3- إمكانية تعديل الحساب ونقله بين:
   - تيك توك
   - تيك توك أرباح
4- إضافة حقول خاصة بحسابات الأرباح:
   - حالة الأرباح (مفعّل / غير مفعّل)
   - الدولة المؤهلة
   - متوسط الربح لكل 10,000 مشاهدة
   - ملاحظات الأرباح
5- إضافة إحصائية:
   "عدد حسابات تيك توك أرباح"
6- دعم البحث والتعديل والحذف والفلترة ورفع الصور تماماً مثل باقي الأقسام.

داخل المتجر:

1- ظهور تبويب مستقل:
   💰 تيك توك أرباح
2- عرض جميع الحسابات التابعة لهذا القسم.
3- إذا كانت الأرباح مفعلة يظهر على البطاقة:

💰 مفعّل الأرباح

4- داخل صفحة التفاصيل يظهر صندوق خاص بمعلومات الأرباح.

========================================
ثانياً: تحويل الحسابات إلى صفحات مستقلة
========================================

الوضع الحالي:
عند الضغط على الحساب يتم فتح نافذة منبثقة.

المطلوب:

1- إلغاء فتح النافذة المنبثقة عند الضغط على البطاقة.
2- إنشاء صفحة مستقلة لكل حساب.

مثال:

/account/123

3- عند الضغط على الحساب يتم الانتقال إلى صفحة التفاصيل الكاملة.

4- صفحة التفاصيل تعرض:
   - الصور
   - اسم الحساب
   - السعر
   - عدد المتابعين
   - الوصف الكامل
   - المميزات
   - حالة الحساب
   - معلومات الأرباح إن وجدت

5- إضافة الأزرار التالية داخل الصفحة:
   - شراء عبر واتساب
   - زيارة الحساب

6- إضافة زر رجوع للعودة إلى صفحة الحسابات.

7- لكل حساب رابط خاص يمكن مشاركته مباشرة.

========================================
ثالثاً: تعديل ترتيب الصفحة الرئيسية
========================================

حالياً يظهر قسم:

"لماذا متجر فلسطين؟"

في أعلى الصفحة.

المطلوب:

نقل قسم:

"لماذا متجر فلسطين؟"

بجميع محتوياته إلى أسفل الصفحة قبل الفوتر مباشرة.

========================================
الترتيب الجديد للصفحة الرئيسية
========================================

1- الشعار واسم متجر فلسطين
2- العنوان الرئيسي والوصف
3- زر تصفح الحسابات
4- زر تواصل معنا
5- أقسام الحسابات مباشرة:

   - تيك توك
   - تيك توك أرباح 💰
   - إنستغرام
   - فيسبوك

6- جميع الحسابات المعروضة
7- آخر الحسابات المضافة
8- قسم "لماذا متجر فلسطين؟"
9- الفوتر

مهم جداً:

مكان قسم "لماذا متجر فلسطين؟" الحالي يجب أن يتم استبداله مباشرة بأقسام الحسابات، وليس ترك مساحة فارغة.

الهدف:

عند دخول الزائر للموقع يرى أقسام الحسابات والحسابات المعروضة مباشرة، بينما يظهر قسم الثقة والمميزات في نهاية الصفحة فقط.
