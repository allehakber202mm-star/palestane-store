فحص شامل وعميق لمشكلة لوحة التحكم admin/accounts وإصلاحها بالكامل.

المشاكل الحالية:
1- الحسابات الجديدة تظهر في المتجر العام ولكن لا تظهر في لوحة التحكم.
2- العديد من الحسابات تعرض مربع أبيض/رمادي أو "لا توجد صورة" رغم أن الحساب موجود وصورته تظهر في المتجر.
3- لوحة التحكم تبدو وكأنها تعرض بيانات قديمة أو غير متزامنة مع المتجر.

المطلوب تنفيذ فحص شامل للنظام بالكامل:

DATABASE:
- تحديد قاعدة البيانات المستخدمة في المتجر العام.
- تحديد قاعدة البيانات المستخدمة في admin/accounts.
- التأكد أن الاثنين يستخدمان نفس قاعدة البيانات ونفس الجداول.
- فحص عدد الحسابات الحقيقي داخل قاعدة البيانات.
- مقارنة عدد الحسابات في المتجر مع عدد الحسابات في لوحة التحكم.
- البحث عن أي جداول قديمة أو نسخ مكررة للبيانات.
- فحص جميع الحقول الخاصة بالصور (image, image_url, thumbnail, photo, photo_url وغيرها).

API:
- فحص جميع API المستخدمة في المتجر ولوحة التحكم.
- التأكد أن admin/accounts تستدعي نفس البيانات التي تظهر في المتجر.
- إزالة أي API قديمة أو غير مستخدمة.
- توحيد مصدر البيانات بين المتجر ولوحة التحكم.

IMAGES:
- فحص سبب ظهور "لا توجد صورة".
- التحقق من أن جميع الصور يتم جلبها من قاعدة البيانات بشكل صحيح.
- إصلاح روابط الصور المكسورة.
- إصلاح صور الحسابات المستوردة من تيليجرام.
- إضافة onError fallback للصور المعطلة.
- تسجيل أي أخطاء صور داخل Console.
- التأكد أن أي حساب يملك صورة في قاعدة البيانات يعرض الصورة داخل لوحة التحكم.

ADMIN PAGE:
- مراجعة ملف admin/accounts بالكامل.
- إزالة أي كود قديم أو بيانات ثابتة أو Mock Data.
- إزالة أي Cache أو Local Storage يسبب عرض بيانات قديمة.
- التأكد أن الصفحة تجلب البيانات مباشرة من قاعدة البيانات عند كل تحميل.
- التأكد أن الحسابات الجديدة تظهر فوراً بدون الحاجة لإعادة نشر الموقع.
- ترتيب الحسابات من الأحدث إلى الأقدم حسب created_at DESC.
- إزالة أي LIMIT أو Pagination أو Filter يمنع ظهور الحسابات الجديدة.

DEBUG:
- إنشاء تقرير Debug مؤقت داخل Console يحتوي على:
  * عدد الحسابات في قاعدة البيانات.
  * عدد الحسابات التي تصل للواجهة.
  * عدد الحسابات التي يتم عرضها فعلياً.
  * عدد الصور الناجحة.
  * عدد الصور الفاشلة.
  * أي أخطاء API أو Database.

FINAL CHECK:
- التأكد أن جميع الحسابات الموجودة في المتجر تظهر أيضاً في لوحة التحكم.
- التأكد أن جميع الصور الظاهرة في المتجر تظهر أيضاً في لوحة التحكم.
- التأكد عدم وجود بيانات قديمة أو غير متزامنة.
- إصلاح أي مشكلة تمنع ظهور الحسابات الجديدة أو صورها.

بعد الانتهاء أعطني تقريراً مفصلاً يوضح السبب الحقيقي للمشكلة والملفات التي تم تعديلها والإصلاحات التي تم تنفيذها.
